Clarity on Fire hydrant and sprinkler system
- Firehydrant system purpose is to use as hydrant valve that are given tapping at different places, ideally there should be no hydrant pump running, only so called jacking pump should be running, to just hold the pressure, and this hydrant system line valve which are notioned as H#XXX type valves, they are simply manual valves that you can see most places 
- While Sprinkler system purpose is completely for DV - Deluge valve operation, that is, it is simply used for that purpose only, in DV for sensing line, this sprinkler header line taken from header line before isolation valve for sensing purpose called "Sensing line" which is used for quartz bulbs this thing, and this DV main line has upstream and downstream manual valve in between DV valve. This sensing line has usually pressure around 3ksc, using reducer from the main line. Hence if main pressure drops, leading to DV operation.
